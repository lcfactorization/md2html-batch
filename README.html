md2html_batch — Markdown 批量转模板 HTML

快速使用

方式一：双击 bat（最简单）

把 md2html.bat 复制到任意含 .md 文件的目录，双击运行。

方式二：命令行

:: 转换当前目录所有 .md
md2html.bat

:: 转换指定目录
md2html.bat -d C:\Docs

:: 输出到指定目录
md2html.bat -d C:\Docs -o C:\Output

:: 只转换指定文件
md2html.bat file1.md file2.md

:: 跳过确认
md2html.bat -y

方式三：直接调用 Python

python md2html_batch.py -d . -o ./html_output

依赖

  • Python 3.6+（无第三方包）
  • Pandoc（需在 PATH 中，下载：https://pandoc.org/installing.html）

功能特性

  • 明暗主题切换（右上角按钮，自动记忆偏好）
  • 回到顶部按钮（滚动超过 300px 自动出现）
  • Alert 组件（[!NOTE] [!TIP] [!WARNING] [!IMPORTANT] [!CAUTION]）
  • 风险/等级标签样式
  • 响应式布局（手机/平板/桌面自适应）
  • 打印优化
  • 零外部依赖（单文件 HTML，浏览器直接打开）

文件说明

文件 说明
md2html_batch.py 核心脚本，包含 CSS/JS/转换逻辑
md2html.bat Windows 批处理入口
